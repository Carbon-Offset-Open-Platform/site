# SCOOP landing page (static)

Plain static site: `index.html` plus `assets/`. No build step.

- **GitHub Pages:** push this folder to a repo, then Settings > Pages > Deploy from branch `main`, folder `/ (root)`.
- **Vercel:** import the repo at vercel.com/new, framework preset "Other", no build command, output directory `.`.

Credits: Earth texture and OCO-2 model from NASA 3D Resources (public domain). 3D viewer: Google model-viewer 3.5.0 (Apache 2.0).
